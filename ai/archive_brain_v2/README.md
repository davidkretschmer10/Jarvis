# Brain V2 Archive

Tato část je archivovaná pro budoucí Brain V2. Aktuální verze Jarvise používá pouze Llama 3.

Tento adresář obsahuje nepoužívané konfigurace, routing logiku a modelové definice z předchozích verzí, které byly deaktivovány za účelem zrychlení startu a stabilizace chování systému.
